# data/ — графы данных G

Отвечает за то, чтобы получить граф данных G в виде `search.graph.Graph` с теми же размерами, что в статье NeuGN.

## Файлы

### [loaders.py](loaders.py)

Скачивание, разбор и приведение к простому неориентированному графу с целочисленными метками.

- **`_download(url, name) -> Path`** — качает файл в `data/raw/<name>`, если его там ещё нет. Сначала пишет в `<name>.part` и переименовывает только после успешного завершения, поэтому оборванная загрузка не останется в кэше как «готовый» файл. Использует `curl`, если он есть: Python с python.org на этой машине не видит системных сертификатов и падает с `CERTIFICATE_VERIFY_FAILED`. Проверка SSL не отключается.
- **`load_hamster() -> Graph`** — KONECT `petster-hamster`.
  - Из архива читаются два файла: `ent.petster-hamster` (метаданные: строка на вершину, поля в кавычках через пробел) и `out.petster-hamster` (рёбра, по одному на строку).
  - Метка — поле `species` (4-я колонка, 16 значений: «Hamster (Syrian)», «Gerbil (Mongolian)», …). Номер метки = позиция названия в лексикографически отсортированном списке.
  - Вершины без строки в `ent` (5 штук) выбрасываются вместе с их рёбрами. Итог: **2 421 / 16 621 / 16** — ровно как в статье.
  - Вершины перенумерованы в 0..n−1 по возрастанию исходного KONECT id.
- **`load_lastfm() -> Graph`** — SNAP `lastfm_asia.zip`.
  - Внутри архива папка называется с опечаткой (`lasftm_asia/`), поэтому файлы ищутся по окончанию имени.
  - `lastfm_asia_edges.csv` — рёбра, `lastfm_asia_target.csv` — метка (страна). id уже 0..7623.
  - Итог: **7 624 / 27 806 / 18**.
- **`LOADERS`, `load(name)`** — реестр по имени (`"hamster"`, `"lastfm"`). Все скрипты получают граф только через `load(name)`; новый граф = новая функция + запись в `LOADERS`.

### `__init__.py`

Пустой, делает `data` пакетом.

## Папки (не в коде)

| Папка | Что лежит | Кто пишет |
|---|---|---|
| `raw/` | Скачанные архивы (`petster-hamster.tar.bz2`, `lastfm_asia.zip`). В `.gitignore`. | `loaders._download` |
| `queries/<graph>/size<N>_<density>.json` | Фиксированные наборы запросов для оценки (по 200 штук) | `queries/generate.py` через `queries/storage.py` |
| `queries/hamster_val/size20_dense.json`, `size32_sparse.json` | Валидационные наборы по 40 запросов (другой сид) для подбора α и глубины p/c, чтобы не подгонять под тестовые | одноразовый скрипт, сид в `meta` |
