# queries/ — запросы Q

Генерирует запросы так же, как NeuGN (случайное блуждание по G → индуцированный подграф), сохраняет фиксированные наборы для оценки и сериализует запрос в последовательность вершин вдоль эйлерова цикла (это вход Transformer'а на этапе 3).

## Файлы

### [random_walk.py](random_walk.py) — извлечение запросов

- **`Query`** — dataclass:
  - `graph: Graph` — сам запрос;
  - `origin: list[int]` — `origin[i]` = вершина G, из которой вырезана вершина i запроса. Так как запрос — индуцированный подграф G, `origin` — **известное вложение**, и каждый такой запрос выполним. На этапе 3 это даст правильные ответы для обучения NeuGN.
  - Свойства: `avg_degree` = 2m/n; `density` = `"dense"`, если средняя степень ≥ 3 (`DENSE_MIN_AVG_DEGREE`, порог из NeuGN), иначе `"sparse"`.
- **`random_walk_vertices(g, start, size, rng, max_moves=None)`** — простое случайное блуждание из `start` (следующая вершина — равновероятный сосед). Возвращает различные вершины в порядке первого посещения; `None`, если за `max_moves` ходов (по умолчанию 100·size) не набралось `size` различных. Эта же функция понадобится для обучающих подграфов NeuGN (блуждание из **каждой** вершины G).
- **`sample_query(g, size, rng, start=None)`** — блуждание (из случайной вершины, если `start` не задан) + `induced_subgraph`.
- **`generate_query_set(g, size, density, count, seed, max_attempts)`** — `count` запросов нужной плотности отбором с отклонением (rejection sampling). Может вернуть меньше, если исчерпан лимит попыток; вызывающий код обязан проверить длину (`generate.py` печатает предупреждение). Случайность — `numpy.random.default_rng(seed)`, результат полностью воспроизводим.

### [storage.py](storage.py) — хранение наборов

- **`query_set_path(graph, size, density)`** → `data/queries/<graph>/size<N>_<density>.json`.
- **`save_query_set(path, queries, meta)`** — JSON вида `{"meta": {...}, "queries": [{"labels", "edges", "origin"}, …]}`. В `meta` записываются граф, размер, плотность, seed, лимит попыток — чтобы набор можно было воспроизвести.
- **`load_query_set(path) -> (queries, meta)`** — обратная операция.

Все методы (бейзлайн, random, NeuGN, наши) оцениваются **на одних и тех же сохранённых файлах**.

### [generate.py](generate.py) — CLI генерации

```bash
.venv/bin/python -m queries.generate [--graph hamster lastfm] [--sizes 8 16 20 24 32] \
    [--densities dense sparse] [--count 200] [--seed 0] [--max-attempts 200000]
```

Для каждой комбинации граф × размер × плотность создаёт набор. Seed набора = `seed·1000003 + size·10 + индекс плотности`: наборы разных конфигураций независимы, но воспроизводимы. На Hamster и LastFM все 20 наборов собираются полностью (по 200 запросов) примерно за минуту.

### [euler.py](euler.py) — эйлерова сериализация (для этапа 3)

- **`euler_sequence(q, rng=None) -> list[int]`**:
  - если Q не эйлеров, `networkx.eulerize` дублирует минимальный по весу набор *существующих* рёбер, чтобы все степени стали чётными;
  - затем строится эйлеров цикл из стартовой вершины (случайной, если передан `rng`, иначе 0);
  - возвращается последовательность вершин Q длины (число рёбер после эйлеризации) + 1; цикл замкнут, последний токен = первый.

  Свойства (проверяются тестом): соседние токены всегда смежны в Q, множество соседних пар в точности равно E(Q), поэтому Q восстанавливается по последовательности без потерь. Вершина может встречаться несколько раз — в NeuGN `[Cls]`/ID ставится на все её вхождения.
- **`edges_of_sequence(seq)`** — множество рёбер, задаваемых соседними токенами (для проверки).

Циклический сдвиг номеров вершин Q (i' = (i + r) mod 64) относится к модели и будет в `models/`.
